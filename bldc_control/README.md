# BLDC FOC 驱动项目代码工程



## AS5600线束颜色说明

* 红色:  5V (VCC)
* 黑色 : GND
* 棕色 : PWM
* 蓝色: PGO
* 白色 : DIR ( 输入引脚（DIR）根据旋转方向选择输出的极性。如果DIR接GND，则输出值随顺时针旋转而增加。如果DIR连接到VCC，则输出值随着逆时针旋转而增加。本项目DIR接到GND)
* 黄色 : SCL
* 绿色  : SDA
